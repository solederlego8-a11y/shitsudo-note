加湿器 畳数の選び方｜適用床面積(JEM1426)の読み方と注意点

加湿器の箱や商品ページには「〜畳まで」と書かれていますが、洋室と和室で2つの数字が並んでいることがあります。その意味と、自分の部屋に当てはめるときの注意点を、メーカー公式の仕様表の注記で確認できた範囲で整理します。

適用床面積の定義（仕様表の注記）

シャープの加湿器HVT55の仕様表には、加湿の適用床面積（目安）は日本電機工業会規格（JEM1426）に基づき、プレハブ住宅洋室の場合を最大適用床面積とし、木造和室の場合を最小適用床面積としたもの、とあります。さらに、壁・床の材質、部屋の構造、使用暖房器具などによって適用床面積は異なるので、販売店に相談するよう書かれています。パナソニックのFE-KXP23の仕様表にも、ほぼ同じ趣旨の注記があります。

つまり、仕様表の「畳数」は、住宅の条件ごとの幅を持った目安です。部屋が木造か鉄筋か、窓や壁、暖房の種類で変わります。

仕様表の表記を比べる

機種（出典の仕様表）プレハブ洋室（最大）木造和室（最小）
シャープ HVT55（ハイブリッド式）15畳（25㎡）9畳（15㎡）
パナソニック FE-KXP2364畳（106㎡）39畳（64㎡）

同じ規格に基づく表記でも、機種によって数字は大きく違います。ここに載せたのは仕様表にある数字だけで、他の機種や、より小さい部屋向けの機種の数字はそれぞれの仕様表で確認してください。

自分の部屋への当てはめ方

  1. 部屋の畳数（または㎡）と、木造か鉄筋・コンクリートかを確認する。
  2. 仕様表の2つの数字のうち、自分の住宅に近い方を見る。迷う場合は、最小値である木造和室の数字を基準にすると、小さい方で判断することになる（定義から導ける読み方です）。
  3. 使用する暖房器具や、部屋の仕切り（ドアを開けて隣室とつながるか）で条件が変わることを前提にする。
  4. 気になる場合は販売店に相談する（メーカー注記が案内している対応です）。

加湿量の条件に注意

シャープの仕様表では、加湿量はJEM1426に基づき、ハイブリッド式の場合は20℃・30%のときの値とされています。数値の例として、強550mL/h、静音200mL/h、エコ（強）390mL/hが載っています。ハイブリッド式は室内の温度・湿度によって加湿量が変化し、雨の日など湿度が高いときや室内の温度が低いときは水が気化しにくいため、加湿量は減少すると書かれています。パナソニックの仕様表にも、自己調湿機能があるため高湿になると加湿量が減少するという注記があります。

見る項目確認する理由
適用床面積（洋室・和室）部屋に合わせた目安の幅を知る
加湿量の条件（20℃・30%等）実際の部屋では条件が違い、加湿量は変わる
加湿方式（気化式・スチーム式・ハイブリッド式など）方式で手入れや注意点が異なる。スチーム式は蒸気や内部の湯による子どものやけどにNITEが注意喚起
手入れの頻度取扱説明書の「お手入れ」で確認

NITEは2022年1月の発表で、スチーム式の蒸気や転倒時の湯によるやけどに注意し、子どもを近づけない場所に平坦で安定して置くよう呼びかけています。置き場所の判断は、取扱説明書とNITEなどの案内に従ってください。

買う前に仕様表で確認したい項目

  1. 適用床面積の注記（JEM1426に基づく、と書かれているか）。
  2. 加湿量の条件（温度・湿度の条件）と、運転モードごとの数値。
  3. タンク容量と、給水の頻度の想定。
  4. 加湿方式と、手入れの項目（取り外す部品、洗い方、頻度）。
  5. 交換部品（フィルターなど）の有無と、取扱説明書に書かれた交換の目安。
  6. 保証期間と、補修用性能部品の保有期間。

畳数の数字は選ぶ入口にすぎません。手入れの負担や保証、置き場所も合わせて判断してください。

仕様表を読むときの注意点

  • 畳数の数字は、メーカーが規格にもとづいて示した目安で、実際の加湿の効果を保証するものではありません。
  • パナソニックFE-KXP23のように大きな畳数の表記の機種もあり、家庭向けの数字とは桁が違うことがあります。商品ごとの仕様表で確認してください。
  • 加湿量の数値は条件付きです。20℃・30%という条件と、実際の部屋の温湿度は一致しません。
  • 運転モードで加湿量が変わります。シャープHVT55では強550mL/h、静音200mL/hなどの記載があり、静かな運転では加湿量が小さくなります。
疑問確認方法
自分の部屋は和室か洋室か木造か間取り図や住宅の資料で確認
仕様の表記に二つの数字がある理由注記（JEM1426）を読む
自宅に近い条件の判断がつかない販売店に相談（メーカー注記が案内）

確認できていないこと

JEM1426の規格書そのものの内容、鉄筋・マンションの場合の換算、他社の機種ごとの畳数は、一次情報を開いて確認できていないため書いていません。ここで引用したのは、シャープとパナソニックの仕様表の注記と数字だけです。

相談するときに伝えること

販売店に相談するときは、部屋の畳数と構造（木造か鉄筋か）、使う暖房器具、ドアの開け閉めの状況、使う時間帯を伝えると、適用床面積の見方を聞きやすくなります。メーカーも、壁・床の材質、部屋の構造、使用暖房器具などで適用床面積が異なるため、販売店への相談を案内しています。

比較表を作るときは、機種名、洋室と和室の数字、加湿量の条件、手入れの頻度を同じ列に並べ、出典のページと確認した日付も書き添えておくと、後から見返しても数字の根拠を追えます。

よくある質問

6畳の部屋なら適用畳数6畳の加湿器で足りますか？

仕様表には洋室と和室の2つの数字が載り、木造和室の方が小さい値です。メーカーは壁・床の材質、部屋の構造、暖房器具などで適用面積は変わるとしており、販売店への相談を案内しています。断定はできません。

JEM1426とは何ですか？

メーカーの仕様表の注記には、一般社団法人日本電機工業会の規格（JEM1426）に基づく適用床面積の目安と記載されています。規格書そのものの内容は本稿では確認できていません。

加湿量はいつも仕様表どおり出ますか？

シャープの仕様表では、加湿量はJEM1426に基づく20℃・30%のときの値で、ハイブリッド式は室内の温度・湿度で変化し、湿度が高いときや室温が低いときは減少すると書かれています。

畳数が大きい機種を選べば安心ですか？

畳数の大小だけでは判断できません。手入れのしやすさや保証、置き場所も合わせて取扱説明書で確認してください。
