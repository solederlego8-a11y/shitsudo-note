春から押し入れや棚に保管していた加湿器を、11月になって再び使い始めるとき、そのまま水を入れてスイッチを入れてよいのか。東京都保健医療局と足立区の衛生管理の案内、NITE（製品評価技術基盤機構）の注意喚起を開いて、使い始めの前に確認する項目を手順に整理しました。機種ごとの分解や洗浄の方法は取扱説明書が基準です。この記事は、説明書を読む前に「どこを見るか」をそろえるための確認ノートです。

なぜ使い始めに点検と洗浄が要るのか

東京都保健医療局のリーフレット「知っていますか？レジオネラ ―加湿器の衛生管理―」は、給水タンクや給水トレイなど水が停滞するところでは、レジオネラ属菌のすみかとなるぬめり（生物膜）が作られやすいと説明しています。とくに超音波式加湿器は、タンク内の水をそのまま微細な水しぶきとして放出するため、タンク内の水がレジオネラ属菌で汚染されると、菌も一緒に空間へ放出されてしまうとしています。

足立区の「家庭用加湿器の維持管理」も、加熱をしないタイプの超音波式・遠心式などでは、タンク内での生物膜の生成により、レジオネラ属菌をはじめとする微生物が繁殖して汚染が起こりやすくなるため注意が必要としています。保管中に水が残っていたり、乾燥が不十分だったりした場合は、この汚染の条件がそろいやすくなります。そのため両自治体とも、使い始めの洗浄を管理のポイントに挙げています。

タンクとトレイの洗浄手順

東京都保健医療局の「管理のチェックポイント」は、次の4点を挙げています。

  • 加湿器の給水には水道水を使う。水道水に含まれる残留塩素には消毒効果があり、ぬめりの発生を抑えることができる
  • 給水タンク内や給水トレイに残った水は全て捨て、毎日水を入れ替えて容器を洗浄する
  • ぬめりが見つかった場合は、拭き掃除やこすり洗い等をして除去する。レジオネラ属菌は乾燥に弱いため、水に触れる部分を乾燥させることも有効
  • 使用終了時には乾燥させてから保管し、使用再開時にはよく洗浄してから使用する

足立区の案内も、タンクの水は水道水等の衛生的な水を使い、水のつぎ足しはやめること、タンク内部を定期的に洗浄すること、長時間使用しない時は水を抜き、汚れを取り除いて乾燥させることを挙げ、メーカーの取扱説明書に従って維持管理するよう案内しています。つまり使い始めの洗浄は、シーズン中の「毎日の入れ替え」とセットで考えるものです。シーズン中のカビ・臭いを防ぐ手入れの頻度は、当サイトの「加湿器 カビを防ぐ手入れ」の記事にまとめています。

フィルターと電源コードの確認

NITEの注意喚起「加湿器、空気清浄機及び除湿機の事故防止について」は、フィルターをつけて使用する製品ではフィルターのつけ忘れに注意し、使用方法を守ること、定期的にフィルターの点検・掃除を行うことを挙げています。保管前に外したフィルターを戻し忘れるのは、使い始めに起こりやすい確認漏れです。フィルターの交換時期の目安はメーカーごとに異なるため、当サイトの「加湿器 フィルター交換時期」の記事と取扱説明書で確認してください。

電源コードについては、NITEは、無理に引っ張ったり机の足で踏んだりと、電源プラグや電源コードに過度に力が加わる使い方はしないよう案内し、変形や断線した部分から発火するおそれがあるとしています。別の注意喚起では、給水タンクには水道水を入れ、指定以外の薬剤などは入れないこと、満水ラインを超えて水を入れないこと、水あかは定期的にお手入れし、機器全体を丸洗いしないこと、リコール対象になっていないかを確認することも挙げられています。保管中にコードをきつく巻き付けていた場合は、使い始める前に傷みがないかを見ます。

リコールの確認と異常があったとき

  1. 型番を確認し、消費者庁のリコール情報サイトやメーカー公式ページで、リコール対象になっていないかを調べる。
  2. タンクとトレイを洗浄し、ぬめりを除去して乾燥させる。
  3. フィルターを正しく取り付け、汚れと傷みを確認する。
  4. 電源コードとプラグに、変形・断線・傷みがないかを確認する。
  5. 水道水を満水ライン以下で入れ、短時間運転して、異臭・異音・水漏れがないかを見る。

洗浄しても臭いが取れない、コードに傷みがある、運転に異常がある場合は、そのまま使い続けず、型番を手元に用意してメーカー窓口に相談します。臭いの原因の切り分けは、当サイトの「加湿器 臭いの原因と対処」の記事で整理しています。

確認できていないこと

機種ごとの分解・洗浄の可否、使える洗剤の種類、フィルターの具体的な交換年数は、取扱説明書とメーカー公式の情報で確認する必要があります。この記事では、特定の機種の洗浄方法や、洗剤の可否は扱っていません。また、レジオネラ症の症状や治療については医療の領域のため扱わず、衛生管理の案内の範囲にとどめています。東京都と足立区以外の自治体の案内文は、今回は開いて確認していません。

まとめ

保管していた加湿器の使い始めは、タンクとトレイの洗浄とぬめりの除去、フィルターの取り付けと点検、電源コードの傷みの確認、リコールの確認が柱です。自治体の案内は、給水に水道水を使い、水は毎日入れ替えてつぎ足しをしないこと、使用再開時にはよく洗浄してから使うことを共通して示しています。異常がある場合は使わず、取扱説明書とメーカー窓口の案内に従ってください。

よくある質問

保管していた加湿器は、そのまま使えますか？

東京都保健医療局の案内は、保管してあった加湿器を使い始めるときには、水洗いをするなど洗浄してから使用するとしています。タンクやトレイにぬめりがあれば、拭き掃除やこすり洗いで除去し、水に触れる部分を乾燥させることも有効とされています。

加湿器の給水には何の水を使いますか？

水道水です。東京都保健医療局は、水道水に含まれる残留塩素には消毒効果があり、ぬめりの発生を抑えることができるとしています。NITEも、給水タンクには水道水を入れ、指定以外の薬剤などは入れないこと、満水ラインを超えて水を入れないことを挙げています。

超音波式は特に注意が必要ですか？

足立区の案内では、加熱をしない超音波式などは、タンク内での生物膜（ぬめり）の生成により、レジオネラ属菌をはじめとする微生物が繁殖して汚染が起こりやすくなるため注意が必要とされています。東京都保健医療局も、超音波式はタンク内の水をそのまま微細な水しぶきとして放出するため、汚染されると菌も一緒に放出されると説明しています。

電源コードやフィルターに異常があったらどうしますか？

使用をやめ、メーカー窓口に相談します。NITEは、電源コードに過度に力が加わる使い方で変形や断線した部分から発火するおそれがあること、フィルターのつけ忘れに注意し定期的に点検・掃除を行うことを挙げています。
